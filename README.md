# SBMS - Smart Business Monitoring System 🚀

SBMS is a Python-based network and device monitoring dashboard designed to track the status of Routers, Wireless Access Points, CCTV cameras, and POS terminals in real-time.

## ✨ Features
- **Live Device Monitoring**: Track Online/Offline status.
- **Dynamic Dashboard**: Interactive charts showing device status ratios.
- **Task Management**: Integrated task manager for staff.
- **System Health**: Real-time ping status for internet.

## 🛠️ Tech Stack
- **Backend**: Python (Flask)
- **Database**: MariaDB / MySQL
- **Frontend**: HTML5, CSS3, JavaScript (Chart.js)
